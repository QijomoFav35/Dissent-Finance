Dissent Finance

A vault for a group's money that sits next to an unchanged Sputnik DAO on NEAR. When the DAO approves a spend, it waits for a fixed window, and anyone who did not vote for it can leave with their share first. Each member's agent does this for them, using a key that can only call exit and cancel_spend.

Everything below is read from NEAR mainnet by your browser as the page loads. The agents' notes come from the public repo and are hashed here, then matched against the hashes the exits carried on chain.

Check it without this page

With near CLI. None of these need an account.

near contract verify deployed-at vault.dissentfinance.near network-config mainnet now
near account view-account-summary vault.dissentfinance.near network-config mainnet now
near contract call-function as-read-only vault.dissentfinance.near get_spend json-args '{"spend_id":0}' network-config mainnet now
near contract call-function as-read-only vault.dissentfinance.near get_record json-args '{"from_index":0,"limit":100}' network-config mainnet now
